    Зажатие правой мыши -> Выделение части произведения
    Ctrl + C -> Копирование выделенного фрагмента
    Ctrl + V -> Вставка скопированного элемента

    Ctrl + "+" -> Увеличение масштаба
    Ctrl + "-" -> Уменьшение масштаба

    Распознанные нотные страницы хранятся в "Сохраненных".
    Вы можете выбрать любой из файлов и отредактировать

    Для отправки партитуры нажмите на "Сохранить" в разделе "Редактор",
    указав в "Профиле" адрес электронной почты
